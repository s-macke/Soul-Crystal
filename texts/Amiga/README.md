# Soul Crystal — Amiga-Texte

636 Texte aus den fünf TXT/TAB-Archiven, mit den Text-IDs des Amiga-Spiels:

- [Disk A: Hotel und Umgebung](<Disk 2/DiskA.txt>) — 63 Texte
- [Disk B](<Disk 3/DiskB.txt>) — 199 Texte
- [Disk C](<Disk 2/DiskC.txt>) — 42 Texte
- [Disk D](<Disk 4/DiskD.txt>) — 186 Texte

Die JSON-Dateien daneben enthalten zusätzlich Quelloffsets, Längen und Prüfsummen.
Originale Abstände und Platzhalter bleiben erhalten; Bildschirmumbrüche werden
nicht nachgebildet. Daher können Wörter an ehemaligen Zeilenrändern aneinanderstoßen.

Erneut erzeugen: `GO111MODULE=off go run ./src/Go/amigatext` im Repository-Hauptverzeichnis.
