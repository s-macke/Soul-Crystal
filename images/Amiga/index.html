Soul Crystal — Amiga graphics

Recovered title screens, room artwork, credits and interface graphics.

The default view doubles the height of high-resolution assets to approximate Amiga pixel proportions. The low-resolution cast image keeps its proportions. This is not an exact PAL/NTSC CRT simulation. Click an image for the original-resolution PNG.

Scrolls and font sheets use white on black; runtime fades, copper colour changes and overlays are not reproduced.
